# Jinelle Lin — Portfolio

A bilingual, responsive portfolio website for Jingrou “Jinelle” Lin, an Experience and Communication Designer based in Sydney.

## Features

- Chinese-first homepage with an English language switcher
- Education summary on the homepage; education and experience in the next section
- Selected UI/UX, interaction and visual communication projects
- Education, internship outcomes, awards and project metrics
- Responsive layouts for desktop, tablet and mobile
- Keyboard-accessible project gallery
- No framework or build step required

## Run locally

From this directory:

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000`.

## Publish with GitHub Pages

1. Push the site files to the existing repository's `main` branch.
2. Open **Settings → Pages** in GitHub.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select `main` and `/ (root)`, then save.

The existing public address remains `https://jinellelnn19.github.io/jinelle-portfolio/`.

## Privacy

The public website includes an email address. The phone number and the source portfolio PDF are not published with this site.
